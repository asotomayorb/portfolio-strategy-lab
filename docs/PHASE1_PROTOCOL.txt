FROZEN PRINCIPLES
1. No post-result parameter optimization.
2. Baseline parameters remain the reference.
3. Neighbor tests measure stability/plateaus, not winners.
4. Same universe/protocol whenever the comparison permits.
5. Historical regimes must be separated from current/OOS periods.
6. Robustness > peak CAGR.
7. No winner unless supported across multiple independent robustness dimensions.
8. Value is omitted rather than fabricated when comparable data are unavailable.
